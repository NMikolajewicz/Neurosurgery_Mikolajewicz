## Life-threatening conditions

==PETMAC: PE, esophageal rupture, tension PT, MI, aortic dissection, cardiac tamponade==

* **STEMI/NSTEMI** - ST elevations, dynamic changes, troponin elevation
* **Aortic Dissection** - Tearing pain, pulse/BP differentials, widened mediastinum
* **Pulmonary Embolism** - Sudden onset, dyspnea, hypoxia, risk factors
* **Tension Pneumothorax** - Respiratory distress, absent breath sounds, hemodynamic instability
* **Pericardial Tamponade** - Beck's triad, xc
* pulsus paradoxus >10mmHg
* **Esophageal Rupture** - Severe pain after vomiting, subcutaneous emphysema

## History

FEPPPS - fatigue, edema, pneas (orthopnea, nocturnal, dyspnea), syncope

### Pain

* **Onset**: Sudden vs gradual, activity-related, time of day
* **Provocation**: Exertion, position, inspiration, swallowing
* **Quality**: Crushing, tearing, sharp, burning, pressure
* **Radiation**: Left arm, jaw, back, epigastrium
* **Severity**: 1-10 scale, worst pain ever
* **Timing**: Duration, intermittent vs constant, previous episodes

### Associated

* **Cardiac**: Dyspnea, diaphoresis, nausea, lightheadedness, palpitations
* **Pulmonary**: Cough, hemoptysis, dyspnea, pleuritic pain
* **GI**: Dysphagia, regurgitation, epigastric pain, belching relief
* **Neurologic**: Syncope, focal deficits, headache

### Risk Factors

|     |     |
| --- | --- |
| System | Risk Factors |
| **Cardiac** | Age >40, DM, HTN, smoking, hyperlipidemia, family history, prior CAD |
| **Pulmonary** | Recent surgery/immobilization, malignancy, pregnancy, oral contraceptives |
| **Aortic** | HTN, connective tissue disorders, bicuspid valve, cocaine use |
| **Other** | Recent trauma, immunocompromise, substance use |

## Physical Examination

### Vital Signs - Critical Values

* **Blood Pressure**: Differential >20mmHg between arms (dissection)
* **Pulse**: Rate, rhythm, quality, symmetry
* **Respiratory Rate**: >24 concerning for PE/pneumonia
* **Oxygen Saturation**: <95% on room air
* **Temperature**: Fever suggests infectious etiology

### Focused Physical Exam

|     |     |
| --- | --- |
| System | Key Findings |
| **General** | Distress level, diaphoresis, pallor |
| **Cardiovascular** | Murmurs, gallops, rubs, peripheral pulses, JVD |
| **Pulmonary** | Breath sounds, tactile fremitus, percussion |
| **Abdominal** | Epigastric tenderness, pulsatile masses |
| **Neurologic** | Mental status, focal deficits, symmetry |
| **Extremities** | Edema, cyanosis, clubbing |

### Special Maneuvers

* **Pulsus Paradoxus**: >10mmHg suggests tamponade
* **Kussmaul's Sign**: JVD with inspiration (tamponade, RV failure)
* **Reproducible Chest Wall Pain**: Suggests musculoskeletal cause

## Differential Diagnosis

### Life-Threatening Causes

|     |     |     |
| --- | --- | --- |
| Condition | Key Features | Immediate Tests |
| **STEMI** | ST elevation ≥1mm in 2+ leads | ECG, troponin, cardiology |
| **NSTEMI** | Dynamic ST changes, elevated troponin | Serial ECGs, troponin q6h |
| **Aortic Dissection** | Tearing pain, BP differential | CT angiography, TEE |
| **Massive PE** | Sudden dyspnea, hypoxia, shock | CTPA, bedside echo |
| **Tension PTX** | Absent breath sounds, tracheal shift | CXR, needle decompression |
| **Tamponade** | Beck's triad, pulsus paradoxus | Echo, pericardiocentesis |

### Common Non-Life-Threatening Causes

* **Musculoskeletal**: Reproducible, position-dependent
* **GERD**: Burning, meal-related, antacid relief
* **Anxiety**: Associated psychiatric symptoms, normal tests
* **Pneumonia**: Fever, productive cough, infiltrate on CXR
* **Costochondritis**: Tender costochondral junctions

## Diagnostic Workup

### Essential Initial Tests

|     |     |     |
| --- | --- | --- |
| Test | Indications | Key Findings |
| **ECG** | All patients | ST changes, Q waves, arrhythmias |
| **Chest X-ray** | All patients | Pneumothorax, infiltrates, widened mediastinum |
| **Troponin** | Suspected ACS | myocardial injury |
| **D-dimer** | Low-moderate PE risk | thromboembolism |
| **BNP/NT-proBNP** | Suspected heart failure | volume overload |

### Risk Stratification Tools

#### HEART Score (for ACS risk)

|     |     |     |     |
| --- | --- | --- | --- |
| Factor | 0 Points | 1 Point | 2 Points |
| **History** | Slightly suspicious | Moderately suspicious | Highly suspicious |
| **ECG** | Normal | Non-specific changes | Significant ST changes |
| **Age** | <45 | 45-64 | ≥65 |
| **Risk Factors** | None | 1-2 factors | ≥3 factors |
| **Troponin** | Normal | 1-3x normal | \>3x normal |

**Interpretation**: 0-3 (low risk), 4-6 (moderate risk), 7-10 (high risk)

#### Wells Score (for PE risk)

* DVT symptoms: 3 points
* PE most likely diagnosis: 3 points
* Heart rate >100: 1.5 points
* Immobilization/surgery: 1.5 points
* Previous PE/DVT: 1.5 points
* Hemoptysis: 1 point
* Malignancy: 1 point

**Interpretation**: <2 (low), 2-6 (moderate), >6 (high)

### Advanced Imaging

#### CT Angiography

* **CTPA**: Gold standard for PE diagnosis
* **CTA Chest**: Aortic dissection, PA abnormalities
* **Coronary CTA**: Low-moderate risk ACS with normal initial workup

#### Echocardiography

* **Bedside Echo**: Tamponade, regional wall motion, RV strain
* **Formal Echo**: Detailed cardiac structure/function assessment
* **TEE**: Aortic dissection when CT contraindicated

## Management Algorithms

### Acute Coronary Syndrome Management

* aspirin 325 mg
* clopidogrel 600 mg
* atorvastatin 80 mg
* metoprolol if no c/i
* heparin per protocol
* STEMI: immediate PCI
* NSTEMI: risk stratification

### Pulmonary Embolism Management

|     |     |     |
| --- | --- | --- |
| Severity | Treatment | Monitoring |
| **Massive PE** | tPA + anticoagulation | ICU, hemodynamics |
| **Submassive PE** | Anticoagulation ± tPA | Telemetry, RV function |
| **Low-risk PE** | Anticoagulation | Consider outpatient |

**Anticoagulation Options**:

* Apixaban 10mg BID x 7 days, then 5mg BID
* Rivaroxaban 15mg BID x 21 days, then 20mg daily
* Enoxaparin + warfarin (traditional approach)

### Aortic Dissection Management

* Type A (ascending) - emergent surgery
* Type B (descending) - medical management
* blood pressure control
* pain management
* avoid thrombolytics

**Blood Pressure Targets**: SBP 100-120 mmHg, HR 60-100 bpm

### Pneumothorax Management

|     |     |
| --- | --- |
| Size | Treatment |
| **<20%** | Observation, serial CXR |
| **20-50%** | Needle aspiration or small chest tube |
| **\>50% or tension** | Large chest tube (32-36 Fr) |

## Disposition Guidelines

### Admission Criteria

|     |     |
| --- | --- |
| Condition | Admission Level |
| **STEMI/NSTEMI** | CCU/Cardiac unit |
| **High-risk ACS** | Telemetry unit |
| **Aortic dissection** | ICU/OR |
| **Massive/submassive PE** | ICU/telemetry |
| **Pneumothorax with tube** | Inpatient monitoring |
| **Unstable vitals** | Appropriate level of care |

### Discharge Criteria (Low-Risk Chest Pain)

* HEART score 0-3
* Normal troponin x 2 (0 and 3-6 hours)
* Normal ECG
* Stable vital signs
* Reliable follow-up arranged
* Patient education provided

### Outpatient Follow-up

* **Cardiology**: 1-2 weeks for ACS workup
* **Primary care**: 3-7 days for low-risk chest pain
* **Stress testing**: 72 hours if not done inpatient
* **Anticoagulation clinic**: If starting warfarin

## Special Considerations for Neurosurgery

### Neurologic Causes of Chest Pain

* **Cervical radiculopathy**: C6-C8 distribution
* **Thoracic outlet syndrome**: Position-dependent, upper extremity symptoms
* **Post-operative pain**: After cervical/thoracic procedures
* **Referred pain**: From cervical spine pathology

### Post-Neurosurgical Considerations

* **DVT/PE risk**: Prolonged immobilization, surgery
* **Medication interactions**: With anticoagulants, antiplatelets
* **Positioning effects**: Prone positioning complications
* **Fat embolism**: After spinal instrumentation

### Contraindications in Neurosurgical Patients

* **Anticoagulation**: Recent intracranial surgery
* **Thrombolytics**: Absolute contraindication post-neurosurgery
* **Blood pressure management**: Avoid hypotension if increased ICP
