**Classification: sunderland**

* Type 1 - conduction block (neuropraxia)
	* Focal segmental demyelination
	* Mx: spontaneous recovery (days to weeks)
* Type 2 - axonal injury (axonotmesis)
	* Axon damaged with intact endoneurium
	* Mx: full recovery possible without surgery (regeneration of 2-3 mm per day)
* Type 3 - Type 2 + endometrium injury
	* Axon and endoneurium injured with intact perineurium
	* Mx: Slower regeneration due to scarring. Regeneration of 1 mm per day.
* Type 4 - Type 3 + perineuroum injury
	* Axon, endoneurium, and perineurium injured with intact epineurium
	* Mx: surgical reconstruction.
* Type 5 - Type 4 + epineurium injury (neurotmesis)
	* Complete nerve transection
	* Mx: surgical reconstruction

Type 1: compression
Type 2-4: crush
Type 5: transection
