# Subaxial Cervical Spine Injury Classification and Severity Score (SLICS)

> [!Summary]  
> **SLIC = Morphology + DLC integrity + Neurologic status** (sum points).  
> **Management by total score:** **1–3 non-surgical**, **4 "grey zone/not specified"**, **≥5 surgical**

### SLIC scoring 

| Domain            |                                                                                                                                                     Finding |                                                                  Points |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------: | ----------------------------------------------------------------------: |
| Morphology        |                                                                                                                                          ==No abnormality== |                                                                       0 |
|                   |                                                                    ==Simple compression== <br>(compression fx, endplate disruption, sagittal/coronal VB fx) |                                                                       1 |
|                   |                                                                                                                                          ==Burst fracture== |                                                                       2 |
|                   |                                                                                                   ==Distraction== <br>(perched facet, posterior element fx) |                                                                       3 |
|                   |                     ==Rotation/translation== <br>(facet dislocation, teardrop fx, advanced compression injury, bilateral pedicle fx, floating lateral mass) |                                                                       4 |
|                   |                                                                                                                          Guideline for rotation/translation | Relative axial rotation ≥11° OR any translation not due to degeneration |
| DLC integrity     |                                                                                                                                                  ==Intact== |                                                                       0 |
|                   |                 ==Indeterminate== <br>(isolated interspinous widening with <11° relative angulation & no abnormal facet alignment; ↑T2 signal in ligaments) |                                                                       1 |
|                   | ==Disrupted== <br>(perched/dislocated facet; <50% articular apposition; facet diastasis >2 mm; widened anterior disc space; ↑T2 signal through entire disc) |                                                                       2 |
| Neurologic status |                                                                                                                                                      Intact |                                                                       0 |
|                   |                                                                                                                                                 Root injury |                                                                       1 |
|                   |                                                                                                                                                Complete SCI |                                                                       2 |
|                   |                                                                                                                                              Incomplete SCI |                                                                       3 |
|                   |                                                                                                Continuous cord compression with neuro deficit<br>(modifier) |                                                                      +1 |
*DLC; Disco-ligamentous complex integrity*

> [!Note]  **Don't forget the modifier:** **+1** if **continuous cord compression + neurologic deficit**

### DLC features

- **DLC includes**:
    - **Anterior longitudinal ligament** (==strongest anterior component==)
    - **Posterior longitudinal ligament**
    - **Ligamentum flavum**
    - **Facet capsule** (==strongest posterior component==)
    - **Interspinous + supraspinous ligaments**

### Reliability

- **Inter-rater reliability (ICC)** for SLIC: **0.71**

### Reporting a SLIC injury 

- Include:
    - **Spinal level**
    - **Morphology** (most severe at that level)
    - **Bony injury descriptor** (e.g., TP/pedicle/endplate/articular process/lateral mass)
    - **DLC status** (+ descriptors, e.g., herniated disc)
    - **Neurologic status**
    - **Confounders** (e.g., ankylosing spondylitis, DISH, osteoporosis, prior surgery, degenerative disease)

## SLIC vs TLICS

### Shared structure

- Both are **3-domain point systems** + **management threshold by total points** (nonop vs grey zone vs surgical).
### Thoracolumbar Injury Classification and Severity Score (TLICS)

> [!Summary]  
> **TLICS management:** **≤3 nonoperative**, **4 grey zone**, **≥5 surgical candidate**

|TLICS domain|Finding|Points|
|---|--:|--:|
|**Radiographic morphology**|Compression fx|**1**|
||Burst component **or lateral angulation >15°**|**1**|
||Distraction injury|**2**|
||Translational/rotational injury|**3**|
|**Neurologic status**|Intact|**0**|
||Root injury|**2**|
||Complete SCI|**2**|
||Incomplete SCI|**3**|
||Cauda equina syndrome|**3**|
|**Posterior ligamentous complex**|Intact|**0**|
||Undetermined|**2**|
||Definite injury|**3**|

### High-yield comparison table

|Feature|**SLIC (Subaxial C-spine)**|**TLICS (Thoracolumbar)**|
|---|---|---|
|Region|**C3–C7**|**T/L spine**|
|Ligament domain|**DLC** (disc + ligaments)|**PLC**|
|Max morphology points|**4** (rotation/translation)|**3** (translation/rotation)|
|Root injury points|**1**|**2**|
|Operative threshold|**≥5**|**≥5**|
|Grey zone|**4** ("not specified")|**4** ("grey zone")|
